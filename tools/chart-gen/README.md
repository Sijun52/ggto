# `@ggto/chart-gen` — 시드 차트 생성기 (P2.md 7.1)

HU 푸시/폴드 내시 균형을 직접 풀어 `ggto-json` 차트를 만든다. 외부 차트를 기다리지 않고
파이프라인(포맷 → 임포터 → 저장소 → API → 뷰어 → P3 채점)을 끝까지 검증하기 위한 1순위 시드다.

```
node dist/main.js [--out <dir>] [--stacks 5,8,10,12,15,20] [--iterations 5000] [--equity <file>]
node dist/genEquity.js [--out <file>] [--samples 200000] [--workers 6]   # equity169.json 재생성
```

## 왜 169 클래스로 푸는가 (계산은 1326 이라는 규칙과의 관계)

프리플랍 HU 에는 보드가 없다. 슈트 순열 σ 는 게임의 **자기동형**이다 — 덱, 딜, 핸드 랭킹,
지불이 전부 σ 로 보존되므로 같은 핸드클래스에 속한 콤보들(예: AhKh, AsKs)은 전략적으로
동치이고 균형에서 같은 빈도를 갖는다. 그래서 169 정보집합으로 푼 해는 1326 해와 같다.
**이것은 생성기 안에서만 성립하는 예외다.** 결과는 곧바로 1326 으로 전개해 저장하고
(임포터가 클래스의 모든 콤보에 같은 행을 복사), 도달 레인지·표시 집계·트레이너는 전부
1326 위에서 돈다 (D4). 보드가 생기는 순간(P5) 이 대칭은 깨진다.

## 구성 요소

| 파일 | 역할 |
|---|---|
| `src/equityTable.ts` | `data/equity169.json` 의 형식·검증·해시. 대각선은 대칭성으로 **정확히 0.5** (샘플링하지 않는다) |
| `src/genEquity.ts` | 169×169 표 재생성. 비대각 14,196 쌍을 core MC 로. 쌍 시드 = `fnv1a32("A|B")` → 샤드 수와 무관하게 결정적 |
| `src/pushFold.ts` | CFR+ (regret matching+, 선형 평균, 교대 갱신) + **정확한 best response 로 exploitability 계산** |
| `src/chart.ts` | 해답 → `ggto-json` 문서. exploitability 게이트(< 0.005bb) 를 통과 못 하면 throw |
| `src/main.ts` | CLI. `data/charts/hu-pushfold-<stack>bb.json` 6개 |

## 모델 (문서의 `source.params.model` 과 같은 말)

SB 는 `A`(올인) / `F` 만, 잼을 당한 BB 는 `C` / `F` 만. 림프도 미니레이즈도 없다.
블라인드 SB 0.5 / BB 1, 앤티 없음, 레이크 없음. 손패 분포는 클래스 쌍의 **충돌 없는 콤보
순서쌍 수** w(h,v) 이고 Σ w = 1326 × 1225 = 1,624,350 (카드 제거가 들어 있다).

한 판 전체 기준 지불(SB 시점):
```
SB 폴드           : -0.5
SB 잼 → BB 폴드   : +1.0
SB 잼 → BB 콜     : 2S·eq(h,v) - S
```
파일에 쓰는 EV 는 P2.md 3.3 기준("노드 이후 스택 변화", 폴드 = 정확히 0)으로 변환한 값이다:
```
EV_A[h] = Σ_v p(v|h)·[ (1-c_v)·1.5 + c_v·(2S·eq(h,v) - (S-0.5)) ]     (노드 "")
EV_C[v] = Σ_h p(h|v, h가 잼)·(2S·(1-eq(h,v)) - (S-1))                  (노드 "A")
```

## 품질 근거

- **exploitability 를 실제로 계산한다.** 평균 전략에 대한 양쪽 best response 이득의 합
  (NashConv) 을 구해 `source.params.nashConvBb` 에, 그 절반을 `exploitabilityBb` 에 적는다.
  게이트는 0.005bb 인데 실측은 **1e-7 ~ 1e-8bb** 다 (5,000 반복).
- 성질 게이트는 `test/pushFold.test.ts` 가 고정한다: 모든 스택에서 AA/KK 순수 잼·콜,
  스택이 줄수록 잼 레인지 단조 증가, 20bb 72o 0%, 결정적 출력, EV 부호와 전략의 일치,
  EV 를 정의식으로 재계산해 대조, 반복 4배 증가 시 L∞ < 0.01.
- 에퀴티 표는 알려진 전수 계산값 4개(AA-KK 81.946 / AKs-22 49.893 / AKo-QQ 43.242 /
  72o-AA 11.800)와 **±0.06%p** 안에서 일치한다 (게이트는 ±0.5%p).
- 공개 푸시/폴드 표와의 수치 대조는 **하지 않는다** (출처·모델이 제각각이라 기준이 될 수 없다).
  참고로 10bb 결과는 SB 잼 58.3%, BB 콜 37.4% 다.
